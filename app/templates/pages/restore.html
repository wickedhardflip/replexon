Restore Guide

Before You Start

Stop Plex before restoring to prevent database corruption:

# Snap install
sudo snap stop plexmediaserver

# Apt/deb install
sudo systemctl stop plexmediaserver

Optionally back up the current state first:

sudo cp -a "{{ plex_data_path or '/var/snap/plexmediaserver/common/Library/Application Support/Plex Media Server' }}" \
  "/tmp/plex-pre-restore-$(date +%Y%m%d)"

Full Restore from Daily Mirror

Restores the most recent backup:

rsync -avh --password-file={{ rsync_password_file }} \
  {{ rsync_dest }}/plex-current/ \
  "{{ plex_data_path or '/path/to/plex/data' }}/"

Restore from Weekly Snapshot

List available snapshots:

rsync --list-only --password-file={{ rsync_password_file }} \
  {{ rsync_dest }}/{{ snapshot_dir }}/

Restore a specific snapshot (replace the date):

rsync -avh --password-file={{ rsync_password_file }} \
  {{ rsync_dest }}/{{ snapshot_dir }}/2026-01-01/ \
  "{{ plex_data_path or '/path/to/plex/data' }}/"

Database-Only Restore

If you only need the Plex database (watch history, metadata, ratings, playlists):

rsync -avh --password-file={{ rsync_password_file }} \
  {{ rsync_dest }}/plex-current/Plug-in\ Support/Databases/ \
  "{{ plex_data_path or '/path/to/plex/data' }}/Plug-in Support/Databases/"

If the backup used safe SQLite .backup, remove stale WAL/SHM files:

rm -f "{{ plex_data_path or '/path/to/plex/data' }}/Plug-in Support/Databases/"*.db-wal
rm -f "{{ plex_data_path or '/path/to/plex/data' }}/Plug-in Support/Databases/"*.db-shm

After Restore

  1. Fix ownership to match your Plex install: 
    # Snap: sudo chown -R root:root "/path/to/plex/data"
# Apt:  sudo chown -R plex:plex "/path/to/plex/data"
  2. Start Plex: sudo snap start plexmediaserver or sudo systemctl start plexmediaserver
  3. Verify at http://your-server:32400/web — check libraries, watch history, and server settings

What Gets Restored

RePlexOn backs up Plex configuration, database, metadata, and artwork — NOT media files.

Included: watch history, metadata, ratings, playlists, posters/artwork, server settings, plugin data, preferences
Not included: movies, TV shows, music, and other media files (these must still be accessible at their original paths)
